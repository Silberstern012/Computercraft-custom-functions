# Autocrafting with qio from Mekanism
Needed mods are CC:Tweaked, Mekanism and Supplementaries (idk if I spelled it correctly)

System contains 
- One Main Computer to control the system, 
- Collectors (computer with an ex and importer and an small storage),
- "Itemscanners" (computer with an qio Redstone adapter, to check the amt of items in the qio),
- "Crafters" (Turtles with crafting tables) 

You can add so many "crafter", collectors and itemscanners to it as you want.
